## Enhanced with Learnable Feature Embeddings

This application now includes a sophisticated **learnable feature embeddings system** that dynamically adapts visual patterns and symbols based on contextual keys, providing a "living canvas" experience.

### Key Features

- **Neural Network Infrastructure**: PyTorch-inspired implementation in TypeScript with Tensor operations, modular layers, and learnable embeddings
- **Context-Aware Adaptation**: Automatically adjusts patterns based on time of day, scroll position, viewport size, section, and user interaction state
- **Evidence-Based Design**: Implements circadian-aligned color adjustments, scroll fatigue prevention, and responsive optimization
- **Zone Concept Integration**: Section-specific adaptations aligned with RegimA Zone's holistic approach
- **Living Canvas**: Real-time rendering system with smooth transitions and persistent learning

See [docs/LEARNABLE_FEATURES.md](docs/LEARNABLE_FEATURES.md) for complete documentation.

## Getting Started

1. Run `npm install`
2. Run `npm run dev`

The application will start with adaptive features enabled automatically. Patterns and colors will adjust based on your context (time of day, scroll position, interactions, etc.).
